# ملخص مهمة الوكيل A07 — محرك الدرجات (`packages/grading-engine`) واستديو الدرجات النقي

## 1. المجلدات المملوكة
- `packages/grading-engine/`
- `apps/pwa/src/components/gradebook/`

## 2. العقود التي تقرؤها
- `docs/contracts/grading-engine.md`
- `docs/DESIGN_SYSTEM.md` (الشاشة 4)

## 3. المهام ومعايير القبول
1. بناء حزمة `@techeeer/grading-engine` النقية مع مخطط `iraq-default-v1` والدوال:
   - `evaluate(scheme, data)`
   - `project(scheme, data)`
   - `solveFor(scheme, data, targetNode, targetValue)`
   - `explain(scheme, data, nodeId)`
   - `deriveMonthlyComponents(scheme, events, recordedSessionsCount)`
2. اجتياز كافة متجهات الاختبار في القسم `6.4`:
   - شهر 1 (`90` مكونات، `80` امتحان) = `85`
   - شهر 2 (`80` مكونات، `70` امتحان) = `75`
   - سعي الفصل 1 = `80`، نصف السنة = `70`
   - شهر 3 = `90`، شهر 4 = `80`، سعي الفصل 2 = `85`
   - السعي السنوي = `78.33`، امتحان نهائي `60` -> الدرجة النهائية `69.17` (ناجح)
   - المطلوب للنجاح بسعي `78.33` = `21.67`؛ وبسعي `40 / 30 / 25` = `60 / 70 / 75`
   - اشتقاق الحضور: `25` حصة وغيابان = `18.4` -> بخطوة `0.5` يصبح `18.5`.
3. عدم كسر أي دالة في `@techeeer/core`.
