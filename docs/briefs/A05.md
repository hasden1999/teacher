# ملخص مهمة الوكيل A05 — الغلاف ونظام الواجهات النقي للهاتف أولاً

## 1. المجلدات المملوكة
- `apps/pwa/src/components/layout/`
- `apps/pwa/src/components/common/`
- `apps/pwa/src/index.css`
- `docs/DESIGN_SYSTEM.md`

## 2. العقود التي تقرؤها
- `docs/DESIGN_SYSTEM.md`
- `docs/DECISIONS.md` (القرار D-004)

## 3. المهام ومعايير القبول
1. تطبيق التصميم النقي الجديد للهاتف المحمول (`360px` أولاً):
   - خلفية نقية مريحة (`#F8FAFC`) وبطاقات بيضاء (`#FFFFFF`) بحدود ناعمة بدون ازدحام بصري.
   - شريط علوي مدمج (`52px`) يعرض عنوان الشاشة، اختيار الصف السريع، ونقطة حالة المزامنة النقية.
   - شريط تنقل سفلي رباعي نقي (`64px`): `اليوم` • `الدرجات` • `الأسئلة` • `حسابي`.
2. أهداف لمس لا تقل عن `48px` (`min-h-12`) واستخدام CSS Logical Properties (`ms-`, `me-`, `ps-`, `pe-`).
3. الحفاظ التام على نجاح جميع اختبارات الواجهة القائمة في `apps/pwa/tests/`.
