# المعمارية الموحّدة لمشروع «مساعد المعلم العراقي» (ARCHITECTURE.md)

## 1. نظرة عامة
تجمع هذه المعمارية بين قوة النواة المحلية المختبرة في المستودع (`SQLite WASM OPFS` + `@techeeer/core` + `@techeeer/content`) وبين متطلبات الإصدار الثاني (`docs/PLAN.md`) الخاصة بالمزامنة السحابية الآمنة، وبوابة الذكاء الاصطناعي المحكومة بالكلفة والحصص (`A9`)، ومحرك الدرجات المبني على المخططات (`packages/grading-engine`)، ونظام الواجهات النقي المصمم للهاتف أولاً (`docs/DESIGN_SYSTEM.md`).

---

## 2. طبقات النظام (System Layers)

### 2.1 طبقة جهاز المعلم (`apps/pwa` — Offline-First 100%)
- **إطار العمل:** `React 19` + `Vite` + `Tailwind CSS v4` بخصائص منطقية (`ms-`, `me-`, `ps-`, `pe-`) لدعم العربية `RTL` أصلياً.
- **تصميم الواجهة:** واجهة نقية فائقة البساطة للهاتف المحمول (`360px+`)، تعتمد على شاشة «اليوم» كمركز انطلاق، وشريط تنقل سفلي رباعي، وبطاقات واضحة بلمسة إبهام واحدة.
- **محرك التخزين المحلي:** `@sqlite.org/sqlite-wasm` يعمل في `Dedicated Web Worker` (`sqlite.worker.ts`) فوق `opfs-sahpool` مع قفل `navigator.locks` و7 نسخ احتياطية دائرية في `OPFS` + تصدير/استيراد ملفات نسخ احتياطي `JSON` مشفرة اختيارياً بـ `AES-GCM`.
- **صندوق الصادر والمزامنة (`Outbox Sync`):** كل عملية كتابة محلية تُسجّل في جدول `sync_outbox` بمعرّف فريد `opId` (UUID) وتُرسل بترتيبها عند توفر الاتصال (`POST /sync/push`)، بينما تُسحب التحديثات عبر المؤشر (`GET /sync/pull?cursor=`).

### 2.2 طبقة الحزم النقية المشتركة (`packages/*`)
1. **`packages/contracts`:** مخططات `Zod` المشتركة بين العميل والخادم لجميع الكيانات المزامَنة ومخططات مخرجات الذكاء الاصطناعي الـ 12 (`Section 11.8`).
2. **`packages/grading-engine`:** محرك حساب الدرجات المعتمد على مخطط JSON (`iraq-default-v1`) بلا أي `eval` نصي، ويوفر الدوال الأربع الإلزامية:
   - `evaluate(scheme, data)`
   - `project(scheme, data)`
   - `solveFor(scheme, data, targetNode, targetValue)`
   - `explain(scheme, data, nodeId)`
3. **`packages/arabic-utils`:** تطبيع الأسماء العربية للمطابقة، خوارزمية المطابقة الضبابية للأسماء (`Jaro-Winkler / Levenshtein`)، ومحلل الأرقام العراقية العامية والكسور (`الملحق أ`).
4. **`packages/math-tools`:** محوّل المعادلات النصية الحتمي (العربية/الإنجليزية إلى `LaTeX`) ومكتبة المعادلات الجاهزة للفيزياء والكيمياء والرياضيات.
5. **`packages/core` & `packages/content`:** الحزم التأسيسية القائمة (تشفير `Ed25519`، الساعة المقاومة للتلاعب، محلل نصوص الأسئلة، التقويم العراقي، ومناهج وزارة التربية).

### 2.3 طبقة الخادم وبوابة الذكاء الاصطناعي (`apps/server`)
- **قاعدة البيانات المركزية:** `PostgreSQL` + `Prisma` مع عزل صارم لكل معلم عبر `teacherId` المستخرج من الجلسة الموثقة.
- **بوابة الذكاء الاصطناعي الحصرية (`A9`):**
  - المنفذ الوحيد لنداء `gemini-3.8-flash` (مفتاح من مشروع مفعل عليه الفوترة Paid Tier، مشفر بـ `AES-GCM`).
  - إدارة الحصص والسقف الشهري (`0.50$` افتراضياً بأسعار 2027) وحواجز الأمان العددية لكل ميزة.
  - طابور مهام غير متزامن عبر `pg-boss` مع تقطيع الصوت بـ `ffmpeg` لنمط الإدخال الصوتي `A1`.
- **لوحة تحكم المالك (`/admin`):** إدارة المعلمين، الاشتراكات، مراقبة الكلفة والدقة، إدارة المنهج والتقويم، وأدوات التقييم (`eval-recorder` و`eval-handwriting-kit`).
